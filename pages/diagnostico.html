Diagnóstico

Consulta DNS, mide la latencia HTTP y geolocaliza una dirección IP directamente desde el navegador.

Qué sí y qué no es posible desde el navegador

Por el modelo de seguridad del navegador no se pueden abrir sockets ni enviar paquetes de red arbitrarios. Por eso no están disponibles:

  • ICMP (ping): el navegador no tiene acceso a ICMP ni a sockets crudos.
  • Traceroute: requiere manipular el TTL de paquetes IP, imposible desde JavaScript.
  • Escaneo de puertos: no se pueden abrir conexiones TCP/UDP arbitrarias a puertos.

Sí están disponibles: DNS over HTTPS, medición de latencia HTTP con fetch y geolocalización de IP mediante una API pública.

Aviso de uso responsable

Esta herramienta consulta servicios públicos de Internet. Úsala únicamente en dominios, direcciones IP y equipos que sean tuyos o para los que tengas autorización expresa del responsable. Sondeos a sistemas de terceros sin permiso pueden ser ilegales.
